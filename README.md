# C Exercises

A collection of exercises I write while learning C, from the basics (conditionals and loops) to arrays, functions, pointers and files. I use this repository as a learning log, so new exercises are added as I practice.

## What I've studied

- Conditionals: `if` / `else`
- Loops: `for`, `while`, `do-while` and `break`
- Functions
- Arrays (vectors) and matrices
- Pointers
- File handling
- Basic statistics and data processing

## Exercises

| File | Description |
|---|---|
| `futebol.c` | Prints a league table, then calculates the total, highest and lowest points |
| `estatisticas_do_while.c` | Statistics exercise using loops |
| `exercicios-c/vetor_soma_media_maior.c` | Sum, average and largest value of an array |

## How to run

You need a C compiler such as [GCC](https://gcc.gnu.org/) installed.

```bash
gcc futebol.c -o futebol
./futebol
```

On Windows, run `futebol.exe` instead of `./futebol`. To run another exercise, just change the file name.
